Troubleshooting

rule throws a NoRuleError

A NoRuleError means that no loaded family can produce what you asked for. The message says why, and what would be possible instead.

Forgetting the degree gives a list of what is available on the domain:

julia> using CubatureRules
julia> rule(Simplex{2}())ERROR: rule(Simplex{2}()) needs a `degree`: there is no defensible default, since the right degree depends on the integrand. Available on Simplex{2}():
  ConicalProduct(GaussJacobi)  degrees 0–∞  (derived)
  GrundmannMöller              degrees 0–∞  (derived)
  XiaoGimbutas                 degrees 0–50  (seeded)
Example: rule(Simplex{2}(); degree = 10)

Asking a specific family for a degree it does not have gives the nearest one it does have:

julia> rule(XiaoGimbutas(), Simplex{2}(); degree = 60)ERROR: No rule from XiaoGimbutas exists on Simplex{2}() at degree 60 among the loaded families.
Nearest: XiaoGimbutas degree 50 (445 points).

Requirements that no family can meet together are reported with the families that were excluded and the reason for each:

julia> rule(Simplex{2}(); degree = 9, positive = true, T = Rational{BigInt})ERROR: No rule with positive weights and exact Rational{BigInt} nodes and weights exists on Simplex{2}() at degree 9 among the loaded families.
  XiaoGimbutas (19 points) cannot produce Rational{BigInt}.
  ConicalProduct(GaussJacobi) (25 points) cannot produce Rational{BigInt}.
  GrundmannMöller (35 points) has negative weights.
Nearest: GrundmannMöller degree 1 (1 points, always available).

Here the only family with exact rational rules at this degree (GrundmannMöller) has negative weights. Drop one of the two requirements, or accept a floating-point rule.

A family needs another package

Some families use code from other packages, which have to be loaded first:

julia> rule(Lobatto(), Interval(); degree = 9)ERROR: Lobatto builds its rules with QuadratureRules.jl, which is not loaded; run `using QuadratureRules` first

After using QuadratureRules, Lobatto, Radau and ClenshawCurtis are available and appear in available. See External providers.

A warning about a licence

julia> using Lebedev

julia> rule(Sphere{3}(); degree = 29)
┌ Warning: SphereProduct (450 points) was selected on Sphere{3}() at degree 29;
│ Lebedev (Lebedev.jl, GPL-3) has 302 points but its licence is not one this package
│ can pass on. Pass `copyleft = true` to use it, or
│ `CubatureRules.license_warnings!(false)` to silence this.

This appears when a smaller rule exists but its licence (here GPL-3, from Lebedev.jl) means it is not chosen automatically. You get the larger rule. To use the smaller one, pass copyleft = true or name the family. To turn the warning off, call CubatureRules.license_warnings!(false). Each case warns only once.

A rule takes a long time

Most rules are built in well under a second. Large symmetric rules at high degree and high precision can take minutes. Pass verbose = true to see what is happening:

julia> rule(XiaoGimbutas(), Simplex{2}(); degree = 15, digits = 40, verbose = true);┌ Info: building
│   family = "XiaoGimbutas"
│   domain = Simplex{2}()
│   degree = 15
│   points = 49
│   output = BigFloat
└   working_bits = 134
[ Info: symmetric refinement to degree 15: 11 orbits, 27 unknowns, 27 equations, seed cond 9.77e+01
[ Info:   attempt 1 at 174 bits (134 target + 40 guard)
[ Info: Gauss–Newton: 27 equations, 27 unknowns, 174 bits, cond 9.77e+01, residual 4.014e-16
[ Info:   iter  1: residual 9.035e-32  step 3.034e-17  cond 6.09e+01     0.1 s
[ Info:   iter  2: residual 4.809e-52  step 2.328e-32  cond 6.09e+01     0.1 s
[ Info: Gauss–Newton converged after 2 iterations: residual 4.809e-52, cond 9.77e+01
[ Info: built XiaoGimbutas: 49 points in 0.2 s

The first message is printed before the expensive part starts and shows the size of the problem. After that there is one line per iteration, with the residual, the step size, the condition number and the time taken. verbose = 2 shows more detail, such as the steps of the line search.

The messages are sent with @info, so they can be redirected or filtered with Julia's logging functions like any other log messages.

To stop a long construction from another task, pass a cancellation token:

tok = CubatureRules.CancellationToken()
task = Threads.@spawn rule(UpstreamLebedev(), Sphere{3}(); degree = 125, digits = 100,
                           cancel = tok)
# later
CubatureRules.cancel!(tok)          # the task stops with a CancelledError

Verification fails

If check(r) fails for a rule you built with rule, that is a bug in the package; please report it with the call that produced the rule. The failing part of the report (exactness, sharpness or structure) and the size of the residual help to narrow it down.

For a rule you built yourself, see Verification for what each check tests.
