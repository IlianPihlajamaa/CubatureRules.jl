I want to choose a rule

When you call rule(domain; degree), the package chooses a family for you. To see which families it considered, use available. It lists the candidates without building any of them:

julia> using CubatureRules
julia> available(Simplex{2}(); degree = 17)Candidates on Simplex{2}() for degree ≥ 17, ranked:
  family                       npoints  degree  derivation  positive  interior  symmetry
  XiaoGimbutas                 60       17      seeded      yes       yes       S3
  ConicalProduct(GaussJacobi)  81       17      derived     yes       yes       none
  GrundmannMöller              165      17      derived     no        yes       S3

The list is in the order the selector ranks them: fewest points first, then families that are computed from a formula before families that start from a stored table, then by name. rule builds the first candidate that meets your requirements, and stores the ranking in the rule's provenance:

julia> provenance(rule(Simplex{2}(); degree = 17)).selection"selected by rule(): XiaoGimbutas (60 points) < ConicalProduct(GaussJacobi) (81 points) < GrundmannMöller (165 points); ranked by (npoints, derived before seeded, family name)"

compare gives the same list with two extra columns: whether the family can produce exact rational rules, and a rough estimate of how expensive it is to construct.

julia> compare(Simplex{2}(), 17)Comparison on Simplex{2}() at degree 17:
  family                       npoints  degree  derivation  positive  interior  symmetry  exact_rational  cost
  XiaoGimbutas                 60       17      seeded      yes       yes       S3        no              1.03e+03
  ConicalProduct(GaussJacobi)  81       17      derived     yes       yes       none      no              81
  GrundmannMöller              165      17      derived     no        yes       S3        yes             165

Positive weights and interior nodes

julia> r = rule(Simplex{2}(); degree = 17, positive = true, interior = true);
julia> family(r), npoints(r)("XiaoGimbutas", 60)

With positive = true, families that can produce negative weights are left out. With interior = true, families that can place nodes on the boundary are left out. If no family remains, rule throws a NoRuleError explaining what was excluded; see Troubleshooting.

Negative weights can cost accuracy through cancellation, and can give a negative result for a positive integrand, so it is usually a good idea to ask for positive weights.

Choosing the family yourself

Pass the family as the first argument:

julia> rule(GrundmannMöller(), Simplex{4}(); degree = 11)QuadratureRule{4,Float64} on Simplex{4}()
  family    : GrundmannMöller (derived)
  exactness : polynomial degree 11 (claimed; `check(rule)` verifies)
  points    : 252, all interior
  weights   : some negative, Σw = 0.04166666666666656
  precision : 15 digits
  residual  : 8.6e-17  (defining equations at 63-digit arithmetic: closed form (relative rounding error of the weights))
  reference : Grundmann & Möller (1978), doi:10.1137/0715019

The selector is skipped in that case, and the provenance notes that you chose the family:

julia> provenance(rule(ConicalProduct(), Simplex{2}(); degree = 5)).selection"family chosen explicitly by the caller"

Some families are built out of other families. ConicalProduct(GaussJacobi()) builds a simplex rule from one-dimensional Gauss–Jacobi rules, TensorProduct(Fejer(), 2) builds a rule on a square from Fejér rules, and BallProduct(SphereProduct()) combines a radial rule with a rule on the sphere. When you let the selector choose, it considers all of these combinations along with the other families.

Asking for a number of points

Some families can be asked for a number of points instead of a degree:

julia> r = rule(GaussLegendre(), Interval(); npoints = 12);
julia> degree(r)23

This only works when you name the family, because a number of points only has a meaning for a specific construction.

About the degree

rule returns a rule of at least the degree you asked for. Many families only exist at some degrees, so you may get a higher one:

julia> degree(rule(Simplex{2}(); degree = 8))8

A few families have no polynomial degree at all. TanhSinh, ExpSinh and SinhSinh converge quickly for many integrands, including some with endpoint singularities, but they are not exact on any space of polynomials. Their exactness is recorded as NoClaim, and rule(domain; degree) never selects them. Ask for them by name, as in rule(TanhSinh(5), Interval()). See Exactness claims for how the package deals with this.
