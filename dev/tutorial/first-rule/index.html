I just want a rule

Call rule with a domain and the polynomial degree you need:

julia> using CubatureRules
julia> r = rule(Simplex{2}(); degree = 20)QuadratureRule{2,Float64} on Simplex{2}()
  family    : XiaoGimbutas (seeded, Newton-refined)
  exactness : polynomial degree 20 (claimed; `check(rule)` verifies)
  points    : 79, all interior
  weights   : all positive, Σw = 0.49999999999999994
  precision : 15 digits (guard 12, est. cond(J) = 1.6e+02)
  residual  : 3.7e-16  (defining equations at 43-digit arithmetic: S₃-invariant moment system in orbit parameters (orthonormal Dubiner basis, degree 20))
  reference : Xiao & Gimbutas (2010), doi:10.1016/j.camwa.2009.10.027

This is a rule on the reference triangle that integrates every polynomial of degree 20 or less exactly. Apply it to a function with integrate:

julia> integrate(x -> exp(x[1] * x[2]), r)0.5446001267522241

In more than one dimension the integrand receives the point as an SVector of coordinates, so x[1] and x[2] are its coordinates. In one dimension it receives a number.

Build the rule once

Constructing a rule takes some work, and the package does not cache rules. Create the rule once, outside any loop, and reuse it:

r = rule(Simplex{2}(); degree = 20)
for cell in mesh
    total += integrate(f, r, cell)
end

For the same reason integrate always takes a rule, never a domain. To judge how accurate the result is, see I want an error estimate.

Simplex{D}() works in any dimension, and Disk() is the unit disk.

On an unbounded domain an integral usually only converges with a weight, so these domains come with one. The weight is part of the domain, and integrate includes it for you:

julia> r = rule(LaguerreRay(); degree = 11);   # ∫₀^∞ f(x) e^{-x} dx
julia> integrate(x -> x^5, r)                  # 5! = 120119.99999999999996

HermiteLine() gives ∫ f(x) e^{-x²} dx over the real line, and GaussianSpace(D) its D-dimensional version. The Catalogue lists every domain and the rules available on it.

What the rule contains

julia> r = rule(Simplex{2}(); degree = 5)QuadratureRule{2,Float64} on Simplex{2}()
  family    : XiaoGimbutas (seeded, Newton-refined)
  exactness : polynomial degree 5 (claimed; `check(rule)` verifies)
  points    : 7, all interior
  weights   : all positive, Σw = 0.5
  precision : 15 digits (guard 12, est. cond(J) = 4.8e+00)
  residual  : 3.0e-16  (defining equations at 43-digit arithmetic: S₃-invariant moment system in orbit parameters (orthonormal Dubiner basis, degree 5))
  reference : Xiao & Gimbutas (2010), doi:10.1016/j.camwa.2009.10.027
julia> npoints(r), degree(r), family(r)(7, 5, "XiaoGimbutas")
julia> nodes(r)[1], weights(r)[1]([0.10128650732345634, 0.7974269853530873], 0.06296959027241357)

The summary shows which family was used, the degree, the number of points, and whether the weights are positive and the nodes inside the domain. It also reports how the rule was computed: the working precision and the residual of the equations that define the rule.

The degree is listed as claimed. You can check it yourself with check; see I want to verify a rule.

degree(r) can be higher than the degree you asked for. Many families only exist at certain degrees, and rule then returns the next one up.
